# Foundations of Machine Learning

A beginner-friendly, industry-standard machine learning course delivered in **1-hour daily sessions, 5 days a week, over 4 weeks** (20 hours total). Designed to take a complete beginner from "what is ML?" to understanding and practicing all three core types of machine learning — supervised, unsupervised, and reinforcement learning — and building a simple end-to-end model.

## Course Format

- **Duration:** 4 weeks
- **Schedule:** 1 hour/day, 5 days/week
- **Total content:** 20 hours (20 sessions)
- **Level:** Beginner (no prior ML experience required; basic computer literacy assumed)
- **Style:** Concept + hands-on practice in every session

## Week 1: Foundations — Thinking Like a Machine Learning Practitioner

| Day | Session Title | Trainer | Topics |
|-----|---------------|---------|--------|
| 1 | Introduction to Machine Learning |  | What ML is, how it differs from traditional programming, real-world applications, overview of the three learning types (supervised, unsupervised, reinforcement) |
| 2 | The Machine Learning Workflow |  | Data → model → training → evaluation → prediction; train/test split; why we never test on training data |
| 3 | Python & Data Handling Essentials |  | Variables, data types, working with tabular data, reading a dataset (rows, columns, features, labels) |

## What This Course Covers

- **All three types of machine learning:**
  - Supervised learning (regression and classification)
  - Unsupervised learning (clustering, dimensionality reduction, anomaly detection)
  - Reinforcement learning (agent-environment-reward loop, policies, hands-on demo)
- The complete ML workflow: data prep → training → evaluation → deployment awareness
- Ensemble learning intuition (random forests) and model evaluation (accuracy, precision, recall, overfitting/underfitting, bias-variance tradeoff)
- Feature engineering fundamentals
- The end-to-end ML project lifecycle
- A guided mini-project tying all three learning types together

## What This Course Intentionally Leaves for Later

This is a **foundations** course — deliberately scoped for beginners in 20 hours. It does not go deep into:
- Advanced statistics or linear algebra derivations
- Deep learning / neural networks
- Advanced RL algorithms (Q-learning math, deep RL, policy gradients)
- Cloud deployment and MLOps tooling
- Advanced ensemble methods (gradient boosting internals, XGBoost tuning)
- Full-scale, production-grade projects

These are natural next steps after completing this course.
